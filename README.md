## 🚀 Texnologik Asos

Loyiha hech qanday og'ir backend yoki ma'lumotlar bazasisiz, to'liq statik tarzda ishlaydi:

- **HTML5** — Semantik struktura, Schema.org (`Person`) JSON-LD mikromarkirovkasi, yuqori SEO va qulaylik (Accessibility / WCAG)
- **CSS3** — `#302b63` to'q binafsha rang bazasidagi gradientlar, glassmorphism, Light/Dark rejim o'zgaruvchilari va `@media (prefers-reduced-motion)` qo'llab-quvvatlovi
- **JavaScript (ES6+)** — Ko'p tillilik (UZ / EN / RU), Dark/Light rejim almashtirgichi, spamdan himoyalangan telefon raqami ochilishi, universal nusxalash va toast bildirishnomalari
- **Bootstrap 5.3 & Icons** — Moslashuvchan grid tizimi va zamonaviy ikonkalar
- **Tipografiya** — `Space Grotesk` (Sarlavhalar) va `Inter` (Asosiy matnlar)
